# Balanced report readability

Interactive Rural Senses mockup showing the selected Balanced readability option.

- [Open the mockup](https://rural-senses-ltd.github.io/report-readability-balanced/)
- [Current vs new](https://rural-senses-ltd.github.io/report-readability-balanced/changes.html)
- [Figma: all Balanced cases](https://www.figma.com/design/toyddj4PEriozcxQybp7Sk?node-id=3629-1075)

Includes report body text and links, indicator cards and charts, topics and quotes, and link states. Supports light and dark themes and responsive layouts. Uses static examples and makes no platform API calls.

Serve this directory with any static web server. GitHub Pages publishes the main branch from the repository root.
